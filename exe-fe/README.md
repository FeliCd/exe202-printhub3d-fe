# PrintHub 3D - Frontend Package (`exe-fe`)

Thư mục này chứa toàn bộ mã nguồn Frontend React + TypeScript của dự án PrintHub 3D.

Vui lòng tham khảo tài liệu hướng dẫn cài đặt và thiết lập chi tiết tại **[README.md ở thư mục gốc](../README.md)**.

## Nhanh chóng khởi chạy:

```bash
# 1. Cài đặt phụ thuộc
npm install

# 2. Tạo tệp cấu hình môi trường
cp .env.example .env

# 3. Chạy dev server
npm run dev
```
